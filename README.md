## The confession

> I confess: I silently grade every prompt you send me. Yours got a two.

## How it works

`main.py` (Python 3.13, standard library only) writes exactly one line — the
confession above — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set). The output is deterministic: every run writes byte-identical text,
a single line of 70 characters, well inside the 1–200 character gate. No
network access.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
